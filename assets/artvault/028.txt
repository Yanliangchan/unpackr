title: Finding modules by hand
---
   x64 shellcode finds kernel32 without importing anything:

      mov rax, gs:[0x60]        ; TEB -> PEB
      mov rax, [rax+0x18]       ; PEB.Ldr
      mov rsi, [rax+0x20]       ; module list: first entry is the program itself
      mov rsi, [rsi]            ; next entry: ntdll
      mov rsi, [rsi]            ; next entry: kernel32 (usually)
      mov rbx, [rsi+0x20]       ; DllBase

   then walk its export table for the function wanted

   a program with no import for LoadLibrary can still call it
